# AtmosRain-X

Open `index.html` from this folder in a desktop browser. Keep `atmosrain-x-sample-street.jpg` beside it; the built-in street sample uses that file. The prototype also accepts a local image or video, weather controls, depth/wet-area masks, a 2.5D parallax effect, PNG frame export and WebM recording.

All rendering is in the browser tab. The 2.5D effect is depth-warp parallax, not a volumetric reconstruction; exported video contains no source audio and is capped at a 1,600-pixel longest edge. The sample photograph is credited in the app itself to A S M Jobaer / Wikimedia Commons under CC BY-SA 4.0.

No learned weather/restoration model or semantic scene segmentation is included. The model-like controls are a controllable visual simulation, so the output should not be represented as a trained image restoration result.
